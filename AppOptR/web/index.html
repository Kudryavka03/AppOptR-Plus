简介

AppOpt 是一款 Android 应用调度管理工具。除 CPU 亲和性外，还可为特定应用加入已有 memory cgroup、调整该组内存参数，并为特定线程设置 UCLAMP 与 nice。配置保存后即时热加载，无需重启应用。

使用说明
  1. 规则页点击「添加」，输入应用包名，可同时配置包级默认（可选）与多条线程规则后一次保存
  2. 调优页先创建已有 memory cgroup 的安全路径，再把应用关联到该组；线程规则可设置 UCLAMP min/max 与 nice
  3. 设置页可切换 eBPF / Proc 工作模式、cpuset 目录名、检查间隔与配置文件路径
  4. 配置文件也可直接手工编辑，保存后自动热加载
  5. 更多规则编写说明参考官网文档
